# Ingenious AI — community health defaults

This repository holds the default community health files for all public
Ingenious AI repositories under [@Iceman2050](https://github.com/Iceman2050)
that do not carry their own versions:

- `CONTRIBUTING.md` — how to contribute
- `CODE_OF_CONDUCT.md` — how we treat each other
- `SECURITY.md` — how to report a vulnerability
- `SUPPORT.md` — where to get help
- `.github/ISSUE_TEMPLATE/` — bug report and feature request templates
- `.github/PULL_REQUEST_TEMPLATE.md` — pull request checklist

Maintained by Ingenious AI — https://getingeniousai.com
