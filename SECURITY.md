# Security Policy

## Reporting a vulnerability

If you find a vulnerability in one of our open-source tools, email
**orders@getingeniousai.com** with:

- the repository and version (release tag or commit SHA),
- a minimal reproduction — never live secrets or third-party data,
- the result you observed and the result you expected.

Please do not open a public issue for a suspected vulnerability in a tool
itself. We aim to acknowledge reports within 3 business days and to fix or
document confirmed issues in the open.

## Scope and honesty

Our tools are defensive checkers. A tool's verdict states only what its
documented checks establish; a clean result is never a guarantee that a
system is safe. Each repository's README documents what its checks can and
cannot establish — read the limitations section before relying on a result.
