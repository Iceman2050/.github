# Support

- **Bugs in a tool:** open an issue in that tool's repository using the bug
  report template.
- **Feature ideas:** use the feature request template, or start a
  discussion in the repository if one is enabled.
- **Security reports:** do not use issues — see `SECURITY.md`
  (email orders@getingeniousai.com).
- **Commercial products and the hosted platforms:** https://getingeniousai.com
  — the open-source tools stay fully useful on their own; the platforms add
  continuous monitoring, central management and evidence retention.
